# 🚦 AI-Driven Real-Time Traffic Pattern Prediction

An intelligent traffic analysis and prediction system that uses real-time data from the TomTom API and Machine Learning to estimate congestion levels and traffic patterns.

---

## 📌 Project Overview

This project predicts traffic congestion levels based on real-time traffic data. It integrates API data, processes it, and applies machine learning techniques to provide meaningful insights through an interactive dashboard.

---

## 🛠️ Tech Stack

- **Programming Language:** Python
- **API:** TomTom Traffic API
- **Framework:** Streamlit
- **Libraries:**
  - pandas
  - numpy
  - scikit-learn
  - requests
  - matplotlib / seaborn

---

## ⚙️ Features

- 📡 Fetch real-time traffic data using TomTom API  
- 📊 Predict congestion levels using ML models  
- 📈 Visualize traffic patterns  
- 🌐 Interactive dashboard using Streamlit  
- ⚡ Fast and simple UI for easy understanding
